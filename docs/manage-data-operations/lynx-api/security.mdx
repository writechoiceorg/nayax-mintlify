The Lynx API requires an access token to authenticate requests securely.

## Access token

An access token is a security credential used to authenticate API requests. Each request to the Lynx API must include a valid access token in the `Authorization` header. This access token is also known as an API key or API token, and appears as a User Token in Nayax Core.

<Note>
If you need to issue scoped, time-limited tokens to your own downstream customers or integrations, see [Customer-Managed Access Tokens](/docs/manage-data-operations/lynx-api/customer-managed-tokens) instead.
</Note>

<Warning>
**Keep your tokens safe**

It is important to avoid sharing your secret tokens in public places like GitHub or Bitbucket since it can allow malicious API calls.
</Warning>

Follow these steps in the Nayax Back Office (Nayax Core) to find and copy an access token:

<Steps>
  <Step title="Log in to Nayax Core">
    Use your username and password.
  </Step>
  <Step title="Navigate to Account Settings">
    Click your username in the top right corner, then select **Account Settings**.

    <Frame><img src="/images/docs/security/image1.png" /></Frame>
  </Step>
  <Step title="Open the Security and Login tab">
    It's the second tab, next to **Account**.

    <Frame><img src="/images/docs/security/image2.png" /></Frame>
  </Step>
  <Step title="Find the User Tokens section">
    It's below **Your Trusted Devices**.

    <Frame><img src="/images/docs/security/image3.png" /></Frame>
  </Step>
  <Step title="Show and copy the token">
    Click **Show Token** next to an existing token to reuse it, then copy it for use in API calls.

    <Frame><img src="/images/docs/security/image4.png" /></Frame>
  </Step>
</Steps>

You now have an access token you can send as a Bearer credential on Lynx API requests.

## Using the token in API requests

Include the access token in the `Authorization` header for each API request:

```sh
curl -X GET "https://qa-lynx.nayax.com/operational/v1/devices" \
-H "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
```

Replace `<YOUR_ACCESS_TOKEN>` with your actual token retrieved from Nayax Core.

<Note>
**Environments**

This example uses the QA base URL. See [Environments](/docs/manage-data-operations/lynx-api/lynx-overview#environments) on the Lynx overview page for the full list of base URLs.
</Note>
