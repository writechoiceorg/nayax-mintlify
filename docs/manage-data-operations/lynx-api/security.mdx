The Lynx API requires an access token to authenticate requests securely. This guide provides an overview of generating and using access tokens and best practices for ensuring API security.

## Access Token

An access token is a security credential used to authenticate API requests. Each request to the Lynx API must include a valid access token in the `Authorization` header. This access token is also known as an API key or API token, and appears as a User Token in Nayax Core.

<Warning>
**Keep your Tokens Safe**

It is important to avoid sharing your secret tokens in public places like GitHub or Bitbucket since it can allow malicious API calls.
</Warning>

You manage access tokens in the Nayax Back Office (Nayax Core). Follow these steps to reach the **User Tokens** area, then create a new token or retrieve an existing one:

1. **Log in to Nayax Core** using your username and password.
2. **Navigate to Account Settings** by clicking on your username at the top right corner, and selecting the **Account Settings** option.

    <Frame><img src="/images/docs/security/image1.png" /></Frame>

3. Access the **Security and Login** Tab.

    <Frame><img src="/images/docs/security/image2.png" /></Frame>

4. Navigate down to the **User Tokens** section.

    <Frame><img src="/images/docs/security/image3.png" /></Frame>

### Create a Token

From the **User Tokens** section, create a new token:

1. Click **Add Token**.

    <Frame><img src="/images/docs/security/add-token.png" /></Frame>

2. In the **Add App Token** dialog, enter an optional **Token Name**, set an **Expiration Date**, then click **Generate**.

    <Frame><img src="/images/docs/security/app-token.png" /></Frame>

3. Copy the generated token value and use it in your API calls.

### Retrieve an Existing Token

To reuse an existing token, click the **Show Token** button next to it in the **User Tokens** section, then copy the token for use in API calls.

<Frame><img src="/images/docs/security/image4.png" /></Frame>

## Using the Token in API Requests

Include the access token in the `Authorization` header for each API request:

```sh
curl -X GET "https://qa-lynx.nayax.com/operational/v1/devices" \
-H "Authorization: Bearer <YOUR_ACCESS_TOKEN>"
```

* Replace `<YOUR_ACCESS_TOKEN>` with your actual token retrieved from Nayax Core.

<Note>
**Environments**

All examples in this documentation use the QA base URL: `https://qa-lynx.nayax.com/operational`. For production, replace the hostname with `lynx.nayax.com`.
</Note>
