The EMV Core SDK provides pre-certified EMV payment APIs for kiosk and point-of-sale (POS) developers. The SDK handles card reading, authorization, and server communication so you can focus on your application’s UI and business logic.

This section guides you through using the SDK features. See the following pages for more information:
