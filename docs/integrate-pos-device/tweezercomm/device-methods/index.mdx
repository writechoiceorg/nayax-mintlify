This section covers the API methods for managing payment terminals. Use them to retrieve device information, read card data, configure terminal settings, prompt users for input, control on-screen displays, and send diagnostic logs. The sections below group methods by what they do.

## Device Information & Configuration

<CardGroup cols={3}>
  <Card icon="circle-info" title="getInfo" href="/docs/integrate-pos-device/tweezercomm/device-methods/getinfo">
    Retrieve device metadata, including hardware, manufacturer, and serial number information.
  </Card>

  <Card icon="code-branch" title="getVersion" href="/docs/integrate-pos-device/tweezercomm/device-methods/getversion">
    Retrieve version information for the apps running on the device.
  </Card>

  <Card icon="sliders" title="getProperty" href="/docs/integrate-pos-device/tweezercomm/device-methods/getproperty">
    Retrieve specific terminal details, such as serial numbers or hardware identifiers.
  </Card>

  <Card icon="gear" title="getConfig" href="/docs/integrate-pos-device/tweezercomm/device-methods/getconfig">
    Retrieve the terminal's current configuration object.
  </Card>

  <Card icon="pen-to-square" title="setConfig" href="/docs/integrate-pos-device/tweezercomm/device-methods/setconfig">
    Apply configuration settings to the terminal.
  </Card>

  <Card icon="location-dot" title="getLocation" href="/docs/integrate-pos-device/tweezercomm/device-methods/getlocation">
    Retrieve the device's current geographic location.
  </Card>
</CardGroup>

## Card Reading

<CardGroup cols={3}>
  <Card icon="credit-card" title="readCard" href="/docs/integrate-pos-device/tweezercomm/device-methods/readcard">
    Read card data from the magnetic stripe or NFC reader.
  </Card>

  <Card icon="ban" title="abortReadCard" href="/docs/integrate-pos-device/tweezercomm/device-methods/abortreadcard">
    Cancel an ongoing readCard operation.
  </Card>

  <Card icon="share-from-square" title="readCardForExternalTransaction" href="/docs/integrate-pos-device/tweezercomm/device-methods/readcardforexternaltransaction">
    Read card data so an external processor can authorize the transaction.
  </Card>
</CardGroup>

## User Input & Selection

<CardGroup cols={3}>
  <Card icon="keyboard" title="getUserInput" href="/docs/integrate-pos-device/tweezercomm/device-methods/getuserinput">
    Prompt the user for numeric or alphanumeric input on the terminal.
  </Card>

  <Card icon="ban" title="abortGetUserInput" href="/docs/integrate-pos-device/tweezercomm/device-methods/abortgetuserinput">
    Cancel an ongoing getUserInput request.
  </Card>

  <Card icon="list-check" title="getUserSelection" href="/docs/integrate-pos-device/tweezercomm/device-methods/getuserselection">
    Prompt the user to choose from a predefined list of options.
  </Card>

  <Card icon="ban" title="abortGetUserSelection" href="/docs/integrate-pos-device/tweezercomm/device-methods/abortgetuserselection">
    Cancel an active getUserSelection prompt.
  </Card>
</CardGroup>

## Display & Animations

<CardGroup cols={3}>
  <Card icon="circle-play" title="showAnimation" href="/docs/integrate-pos-device/tweezercomm/device-methods/showanimation">
    Show an approved or declined animation on the device.
  </Card>

  <Card icon="eye-slash" title="hideAnimation" href="/docs/integrate-pos-device/tweezercomm/device-methods/hideanimation">
    Cancel or hide the animation currently showing on the device.
  </Card>

  <Card icon="id-card" title="displaySwipeCard" href="/docs/integrate-pos-device/tweezercomm/device-methods/displayswipecard">
    Prompt the user to swipe a magnetic card on the terminal.
  </Card>

  <Card icon="ban" title="abortSwipe" href="/docs/integrate-pos-device/tweezercomm/device-methods/abortswipe">
    Cancel an ongoing card swipe operation.
  </Card>

  <Card icon="qrcode" title="displayQR" href="/docs/integrate-pos-device/tweezercomm/device-methods/displayqr">
    Show a QR code on the terminal's screen.
  </Card>

  <Card icon="ban" title="abortDisplayQR" href="/docs/integrate-pos-device/tweezercomm/device-methods/abortdisplayqr">
    Cancel an ongoing QR code display.
  </Card>

  <Card icon="ban" title="abortDisplay" href="/docs/integrate-pos-device/tweezercomm/device-methods/abortdisplay">
    Cancel ongoing display operations, such as prompts or messages.
  </Card>
</CardGroup>
