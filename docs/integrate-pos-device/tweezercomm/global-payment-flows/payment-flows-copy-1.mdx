TweezerComm follows structured payment flows to ensure secure and efficient transaction processing. These flows define how different transaction types, such as regular payments, pre-authorizations, and deferred payments, are handled within the system. Understanding these flows enables client applications to integrate appropriately with the Nayax Gateway and optimize payment processing capabilities.

The pages below provide a more detailed description of each one:

  <Card icon="list-check" title="Pre-Selection" href="/docs/integrate-pos-device/tweezercomm/global-payment-flows/tweezercomm-engine-preselection-flow">
    Process, authorize, and settle a payment request before completing the transaction.
  </Card>

  <Card icon="hourglass-half" title="Pre-Authorization" href="/docs/integrate-pos-device/tweezercomm/global-payment-flows/tweezercomm-engine-preauth-flow">
    Process and authorize a transaction, then settle or cancel it based on the payment server's response.
  </Card>
