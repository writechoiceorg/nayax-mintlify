下面列出了每个 C# SDK 版本，从当前版本到首个发布版本。

| Version | Summary |
|---|---|
| **0.0.5.20 (Current)** | **在 `lowlevel_serial_t` 中整合了低级串行接收处理（仅头部帧、友好轮询睡眠和命名读取器线程）；修复了 `vmc_link` 链路断开问题，其中错过的确认让数据包永远挂起并停止保活（重传不再受限于发送超过接收）；`vmc_vend_t` 现在在任何状态下全局处理 `session_end` 和 `send_transfer_data` 以获得更强大的销售流程** |
| 0.0.5.19 | 改进了链接可靠性并修复了虚假重传 |
| 0.0.5.18 | 修复了 rx 和 tx 线程之间关于 `m_pending_tx_msg` 访问的竞态条件 |
| 0.0.5.17 | 添加了 `pre_auth_amount_config`（0x8c）销售子命令，包括消息类、解码/编码支持、工厂方法、事件处理和公开 API；添加了演示菜单选项以与 Java SDK 对齐（检查余额、预付购买、预授权配置、显示消息、关闭套接字） |
| 0.0.5.16 | Marshall 消息中的多销售最大产品数现在根据协商的最大消息大小计算；修复了 `session_end` 超时过早过期的问题，导致 `reader_always_on` 提前触发 |
| 0.0.5.15 | 在所有模块中对齐了 C# SDK 与 Java SDK：修复了 transfer_data 位图常量和多个编码错误（`msg_time_rsp_t`、`msg_setup_max_min_prices_t`、`msg_remote_selection_t`、`msg_expansion_t`、`msg_reader_state_t`）、添加了缺失的消息类和 vposm_ext/ev_ext 消息的工厂分派、添加了 `consumer_id` 和其他 transfer_data 字段、修复了 `vmc_vend_t`、`vmc_general_t`、`vmc_socket_t` 和 `vmc_link` 中众多会话、套接字和通用模块错误 |
| 0.0.5.14 | 为常开模式添加了实时价格变更支持，即使在读取器已启用之后，还添加了健全性检查使得 `vend_request` 和 `close_session` 返回布尔值并拒绝超过允许金额的价格（禁用 `long_price` 时为 65k）；修复了 `msg_single_vend_t` 上的 `session_id` 解码问题并更新了多销售请求日志 |
| 0.0.5.13 | 对齐了 C# SDK 与 Java SDK；修复了 `multi_vend_session_close` 编码 |
| 0.0.5.12 | 添加了防护措施以防止在没有链接时发起销售、套接字和通用操作，防止不必要的崩溃；优化了 `eth_port` 日志 |
| 0.0.5.11 | 移除了不必要的令人担忧的"虚假确认"警告；修复了 `eth_port` 以在 VPOS 重启但 VMC 端的套接字不关闭时恢复，通过关闭和重新连接 |
| 0.0.5.10 | 修复了多销售多会话数据包编码 |
| 0.0.5.09 | 修复了一个可能因缓冲区环绕导致的数据包丢失，触发了重传，以及交易结束后未清除卡数据的错误；`eth_port` 现在可正常使用 |
| 0.0.5.08 | 添加了增强显示控制（VPOSM），具有对 VPOS Touch 设备的向后兼容性，并更新了示例应用程序以支持各种显示控制布局；稳定了 `eth_port` 实现 |
| 0.0.5.07 | 修复了帧大小检测，具有更好的健全性检查以支持不同的 Marshall 消息大小；为端口接口添加了 `flush()` 调用 |
| 0.0.5.06 | 通过 transfer_data 添加了站点 ID 和品牌名称传输到机器，以及一个新的技术员模式命令以远程打开门；修复了单个产品的长价格 |
