Nayax 在此页面记录 Marshall Java SDK 的变化。使用页面顶部的图标订阅 RSS 源，以便在有新发布时获得通知。

<Note>
0.1.6.x patch 系列中的某些功能需要 VPOS 版本 4.0.8.23-RC3 或更新的版本。请查看下表以了解该功能是在哪个 patch 版本中推出的。
</Note>
