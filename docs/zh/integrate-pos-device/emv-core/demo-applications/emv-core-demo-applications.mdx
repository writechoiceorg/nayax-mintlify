本文为测试 Nayax EMV Core 演示应用程序提供了一个统一的入口。Nayax 提供了一个演示应用程序，可帮助您从集成的第一天起验证硬件通信和交易流程，确保在开始自定义开发之前，您的环境已正确配置。

### 为什么从演示应用开始？

- **立即验证 :** 无需编写新代码即可确认您的读卡器与主机系统通信是否正常。
- **参考代码 :** 将演示源代码用作实现您自己支付逻辑的蓝本。
- **网关测试 :** 在受控环境中验证与Nayax网关的连接，并处理测试交易。
