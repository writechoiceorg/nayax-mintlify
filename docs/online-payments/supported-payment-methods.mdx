Online Payments supports the following card networks and digital wallets. Card numbers and wallet tokens are also accepted through the REST API if you're processing customer-initiated transactions directly instead of using the Hosted Payment Page.

| Payment method | Type | Notes |
| --- | --- | --- |
| Visa | Card | Credit and debit |
| Mastercard | Card | Credit and debit |
| American Express | Card | Credit |
| Diners / Discover | Card | Credit |
| Apple Pay | Digital wallet | Available on the Hosted Payment Page, or via the REST API |
| Google Pay | Digital wallet | Available on the Hosted Payment Page, or via the REST API |
