Before you write any code, get access to a sandbox environment and confirm your onboarding requirements with your Nayax contact. This page lists what you need for both sandbox and production.

## Environments

Online Payments provides two external environments, each with its own gateway host.

| Environment | Host | Purpose |
| --- | --- | --- |
| Sandbox | `merchant-api.sb.nayaxpay.com` | Test your integration end to end without processing real payments. |
| Production | `merchant-api.prod.nayaxpay.com` | Process live transactions. |

## Required credentials

Both environments use the same four credentials; only the values differ between sandbox and production.

- `merchantId`
- API key
- `merchantSigningSecret`
- `webhookSigningSecret`

Nayax issues `merchantId`, the API key, and `merchantSigningSecret` as part of onboarding for each environment, and issues production credentials once you complete production onboarding. `webhookSigningSecret` comes later: Nayax generates and shows it once, when you configure your webhook endpoint, so store it as soon as you receive it.

<Warning>
  Onboarding is a prerequisite, not a background task. If it hasn't started, request it from your Nayax contact before you begin integration work. Without credentials, you can't call the sandbox API at all.
</Warning>

## Production onboarding requirements

What you need to go live depends on your operating model.

| Requirement | Direct mode | Payment Facilitator (PF) mode |
| --- | --- | --- |
| Signed commercial agreement with Nayax | Required | Required |
| Production credentials provisioned by Nayax | Required | Required |
| Signed agreement with the acquiring bank | Required | — |
| Merchant ID (MID) issued by the acquirer | Required | — |

## PCI DSS scope

Using the Hosted Payment Page keeps you out of PCI DSS scope for card data capture: Nayax handles, processes, and stores all raw card data, and none of it touches your systems. If you want to [submit card data directly through the REST API](/docs/online-payments/rest-api/authorize-cit) instead, you need proof of valid PCI DSS certification before Nayax allows it.
