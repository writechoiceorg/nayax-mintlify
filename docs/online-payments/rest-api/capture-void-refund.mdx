Once a transaction reaches `authorized`, you can capture it to settle
funds, void it to cancel before capture, or refund it after capture. All
three apply to transactions authorized through both the Hosted Payment
Page (CIT) and the REST API (MIT).

## Capture

`POST /api/v1/transactions/{transactionId}/capture`

Settles a previously authorized transaction. Supported for `final_auth`
and `pre_auth` transaction types.

| Object | Parameter | Required | Format | Description |
| --- | --- | --- | --- | --- |
| path | `transactionId` | Yes | UUID | The authorized transaction to capture. Must have `status: authorized`. |
| `amount` | `amount.value` | No | String, 1-20 characters | Minor units. Provide for a partial capture; omit entirely for a full capture. |
| `amount` | `amount.exponent` | Conditional | Integer | Required when `amount` is provided. |
| `amount` | `amount.currency` | Conditional | String, 3 characters | ISO 4217. Required when `amount` is provided; must match the authorized currency. |

```json
{
  "amount": { "value": "2000", "currency": "USD", "exponent": 2 }
}
```

| Field | Condition | Format | Description |
| --- | --- | --- | --- |
| `transactionId` | Always | UUID | Transaction identifier. |
| `status` | Always | Enum | `captured`, `authorized` (transient failure, retry the capture), or `failed`. |
| `capturedAmount.value` | Always | String | Amount captured, in minor units. |
| `capturedAmount.currency` | Always | String | Currency of the captured amount. |
| `capturedAmount.exponent` | Always | Integer | Decimal places for the captured currency. |
| `errorCode` | On failure | String | A coded reason for the system-level failure; see [Error codes](/docs/online-payments/rest-api/response-codes#error-codes). |

```json
{
  "transactionId": "6c1e2a4d-9f3b-4e21-8a2c-1f9b7d6e5a01",
  "status": "captured",
  "capturedAmount": { "value": "2000", "currency": "USD", "exponent": 2 }
}
```

## Void

`POST /api/v1/transactions/{transactionId}/void`

Fully cancels an approved `final_auth` or `pre_auth` transaction before
capture.

<Note>
  Voiding a `sale` transaction is subject to acquirer support; it isn't
  guaranteed the way it is for `final_auth` and `pre_auth`.
</Note>

| Object | Parameter | Required | Format | Description |
| --- | --- | --- | --- | --- |
| path | `transactionId` | Yes | UUID | The authorized transaction to void. Must have `status: authorized`. |

```json
{}
```

| Field | Condition | Format | Description |
| --- | --- | --- | --- |
| `transactionId` | Always | UUID | Transaction identifier. |
| `status` | Always | Enum | `voided`, `authorized` (transient failure, retry the void), or `failed`. |
| `errorCode` | On failure | String | A coded reason for the system-level failure; see [Error codes](/docs/online-payments/rest-api/response-codes#error-codes). |

```json
{
  "transactionId": "a2e97f31-5c8d-4b6e-9a12-3f7d8e5c1b90",
  "status": "voided"
}
```

## Refund

`POST /api/v1/transactions/{transactionId}/refund`

Returns funds to the customer on a captured transaction. Both full and
partial refunds are supported.

| Object | Parameter | Required | Format | Description |
| --- | --- | --- | --- | --- |
| path | `transactionId` | Yes | UUID | The captured transaction to refund. Must have `status: captured`. |
| `amount` | `amount.value` | Yes | String, 1-20 characters | Amount to refund, in minor units. Must not exceed the captured amount. |
| `amount` | `amount.exponent` | Yes | Integer | Decimal places for the currency. |
| `amount` | `amount.currency` | Yes | String, 3 characters | ISO 4217. Must match the captured currency. |

```json
{
  "amount": { "value": "2000", "currency": "USD", "exponent": 2 }
}
```

| Field | Condition | Format | Description |
| --- | --- | --- | --- |
| `transactionId` | Always | UUID | Transaction identifier. |
| `status` | Always | Enum | `refunded`, `captured` (transient failure, retry the refund), or `failed`. |
| `refundedAmount.value` | Always | String | Amount refunded, in minor units. |
| `refundedAmount.currency` | Always | String | Currency of the refunded amount. |
| `refundedAmount.exponent` | Always | Integer | Decimal places for the refunded currency. |
| `errorCode` | On failure | String | A coded reason for the system-level failure; see [Error codes](/docs/online-payments/rest-api/response-codes#error-codes). |

```json
{
  "transactionId": "6c1e2a4d-9f3b-4e21-8a2c-1f9b7d6e5a01",
  "status": "refunded",
  "refundedAmount": { "value": "2000", "currency": "USD", "exponent": 2 }
}
```
