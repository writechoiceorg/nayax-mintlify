A merchant-initiated transaction (MIT) charges a stored card without the
cardholder present, for example a subscription renewal or an installment on
an earlier purchase. Use this endpoint for that; a customer-initiated
transaction (CIT) goes through the Hosted Payment Page instead.

## Prerequisites

Before you call this endpoint, you need a reusable payment credential and,
in most cases, the original transaction's ID.

- A `scheme_token` from a previous transaction, the confirmed way to reuse
  a card today.
- The original CIT's `transactionId`, from
  [Get transaction](/docs/online-payments/rest-api/transactions#get-transaction)
  or the transaction you processed through the Hosted Payment Page. Pass it
  as `mit.originalTransactionId`.

## Authorize a transaction

`POST /api/v1/transactions/authorize`

Initiates a merchant-initiated purchase, for example a delayed charge, a
recurring payment, or an installment, associated with a previously approved
CIT.

<Warning>
  Set `transaction.initiationType` to `mit` explicitly. It defaults to
  `cit`, so omitting it makes Nayax treat this as a customer-initiated
  request instead.
</Warning>

| Object | Parameter | Required | Format | Description |
| --- | --- | --- | --- | --- |
| `requestData` | `idempotencyKey` | Yes | String, 1-200 characters | Unique per payment attempt. Reuse the same key to retry safely after a timeout; Nayax returns the original result instead of charging twice. |
| `requestData` | `orderId` | No | String, 1-200 characters | Your order reference. Strongly recommended: enables lost-response recovery via [List transactions](/docs/online-payments/rest-api/transactions#list-transactions) filtered by `orderId`. |
| `requestData` | `userId` | No | String, 1-200 characters | Your customer reference. |
| `transaction` | `transactionType` | Yes | Enum | `sale`, `final_auth`, or `pre_auth`. |
| `transaction` | `initiationType` | No | Enum | `cit` or `mit`. Defaults to `cit`; set to `mit` for this flow. |
| `transaction` | `amount.value` | Yes | String, 1-20 characters | Minor units, for example `1999` for $19.99. Integer digits only. |
| `transaction` | `amount.currency` | Yes | String, 3 characters | ISO 4217. |
| `transaction` | `amount.exponent` | Yes | Integer | Decimal places for the currency (`2` for USD/EUR, `0` for JPY, `3` for KWD). |
| `paymentMethod` | `type` | Yes | Enum | `nayax_token` or `scheme_token`. |
| `paymentMethod` | `token` | Conditional | String, 1-200 characters | Required for both `nayax_token` and `scheme_token`. |
| `paymentMethod` | `cryptogram` | Conditional | String, 1-200 characters | Required for `scheme_token`: the token cryptogram (TAVV). |
| `paymentMethod` | `tokenEci` | No | String, 2 characters | Electronic Commerce Indicator (ECI) accompanying a `scheme_token`; recommended. |
| `paymentMethod` | `expiryMonth` | Conditional | String, 2 characters (MM) | Required for `scheme_token`, optional for `nayax_token`. |
| `paymentMethod` | `expiryYear` | Conditional | String, 2-4 characters | Required for `scheme_token`, optional for `nayax_token`. |
| `mit` | `mitType` | Yes | Enum | `unscheduled`, `recurring`, `installments`, `no_show`, `delayed_charge`, `resubmission`, or `split_shipment`. |
| `mit` | `originalTransactionId` | No | UUID | The original CIT's `transactionId`. Optional, but strongly recommended; see the PSD2 warning below. |
| `dynamicDescriptors` | `dbaName` | No | String, 1-200 characters | DBA name on the cardholder's statement. Subject to acquirer support. |
| `dynamicDescriptors` | `phone` | No | String, 1-100 characters | Your phone number on the statement. Subject to acquirer support. |
| `dynamicDescriptors` | `email` | No | String, 1-200 characters | Your email on the statement. Subject to acquirer support. |
| `dynamicDescriptors` | `address` | No | String, 1-300 characters | Your address on the statement. Subject to acquirer support. |

```json
{
  "requestData": {
    "idempotencyKey": "idem_2f8a1c9e7b",
    "orderId": "order_2044",
    "userId": "cust_88213"
  },
  "transaction": {
    "transactionType": "sale",
    "initiationType": "mit",
    "amount": { "value": "2999", "currency": "USD", "exponent": 2 }
  },
  "paymentMethod": {
    "type": "scheme_token",
    "token": "stok_7b3e9f21",
    "cryptogram": "AqIBAwECAQQwMgIBAQIBAA==",
    "tokenEci": "05",
    "expiryMonth": "09",
    "expiryYear": "27"
  },
  "mit": {
    "mitType": "recurring",
    "originalTransactionId": "6c1e2a4d-9f3b-4e21-8a2c-1f9b7d6e5a01"
  }
}
```

`card`, `apple_pay`, and `google_pay` are also accepted as `paymentMethod.type`
values on this same endpoint, for customer-initiated purchases submitted
directly through the API instead of the Hosted Payment Page. That flow is
[covered separately](/docs/online-payments/rest-api/authorize-cit).

<Warning>
  In the EU, under PSD2, an MIT that doesn't reference an authenticated
  original CIT is likely to be soft-declined by the issuer. Set
  `mit.originalTransactionId` whenever you have it.
</Warning>

| Field | Condition | Format | Description |
| --- | --- | --- | --- |
| `transactionId` | Always | UUID | Nayax transaction ID. Store it for lifecycle operations and future MIT references. |
| `status` | Always | Enum | `authorized`, `captured`, `verified`, `declined`, or `failed`. |
| `authCode` | On approval | String | Authorization code from the issuer. |
| `declineCode` | On decline | String | A coded reason for the decline; see [Decline codes](/docs/online-payments/rest-api/response-codes#decline-codes). |
| `rawDeclineCode` | On decline | String | The raw, unmapped decline code from the acquirer or issuer. |
| `errorCode` | On failure | String | A coded reason for the system-level failure; see [Error codes](/docs/online-payments/rest-api/response-codes#error-codes). Safe to retry. |
| `amount` | Always | Object | `value`, `currency`, `exponent`: an echo of the authorized amount. |
| `card.lastFour` | Conditional | String | Last four digits of the card. |
| `card.brand` | Conditional | String | `VISA`, `MASTERCARD`, `AMEX`, or `DISCOVER`. |

```json
{
  "transactionId": "9d4f21e8-3c6b-4a1f-b8e5-2a7c9d1e4f6b",
  "status": "authorized",
  "authCode": "654321",
  "amount": { "value": "2999", "currency": "USD", "exponent": 2 },
  "card": { "lastFour": "4242", "brand": "VISA" }
}
```
