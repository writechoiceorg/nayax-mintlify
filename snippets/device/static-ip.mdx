A static IP is required for the machine. When data comes back to the machine it
passes through a firewall, and without a fixed address the firewall has no way
to route it.

VPOS Media devices support either DHCP or a static IP. DHCP is the default, and
you change it from the device menu.

<Steps>
  <Step title="Open the Technician Menu">
    Tap the top-left corner of the screen repeatedly until the menu appears,
    then select **Technician Menu** and enter the code. The default code is
    `123123`.

    <Frame><img src="/images/image.png" alt="Technician Menu option on the VPOS Media screen" /></Frame>
  </Step>

  <Step title="Go to Communication">
    Scroll down to the **Communication** section.

    <Frame><img src="/images/image-1.png" alt="Communication section in the VPOS Media Technician Menu" /></Frame>
  </Step>

  <Step title="Select Your Connection Type">
    Open **Wifi** or **LAN**, depending on how the device connects.

    <Frame><img src="/images/image-6.png" alt="Wifi and LAN options under the Communication section" /></Frame>
  </Step>
</Steps>

From there, open the network you want and edit its settings. Under
**Advanced**, the **IP settings** field is set to `DHCP` by default and can be
changed to `Static`.

### Configure Wi-Fi

Select the gears icon next to the relevant network.

<Frame><img src="/images/image-15.png" alt="Gears icon next to a Wi-Fi network on the VPOS Media screen" /></Frame>

Select **Advanced**.

<Frame><img src="/images/image-16.png" alt="Advanced option in the Wi-Fi network settings" /></Frame>

Scroll down to **IP settings** and fill in the IP details.

<Frame><img src="/images/image-17.png" alt="IP settings field in the advanced Wi-Fi network settings" /></Frame>

### Configure Ethernet

The steps differ between the two VPOS Media models.

On **VPOS Media 4S**, select the **Ethernet** option directly. The device
prompts you to enable the Ethernet connection and edit its settings.

<Frame><img src="/images/Picture10.png" alt="Ethernet option on the VPOS Media 4S screen" /></Frame>

Open **Setting Ethernet** to enable the static settings, then fill in the
details.

<Frame><img src="/images/Picture11.png" alt="Setting Ethernet screen with the static settings option on VPOS Media 4S" /></Frame>

On **VPOS Media 5**, tap the back arrow at the top left of the Wi-Fi settings
screen to return to the device's system settings.

<Frame><img src="/images/image-11.png" alt="Back arrow at the top left of the VPOS Media 5 Wi-Fi settings screen" /></Frame>

Tap **Network & Internet**.

<Frame><img src="/images/image-10.png" alt="Network and Internet option in the VPOS Media 5 system settings" /></Frame>

Tap **Ethernet**.

<Frame><img src="/images/image-12.png" alt="Ethernet option under Network and Internet on VPOS Media 5" /></Frame>

Turn Ethernet on with the toggle, then tap the **Ethernet** row again to open
**Ethernet Settings**.

<Frame><img src="/images/image-13.png" alt="Ethernet toggle switched on in the VPOS Media 5 settings" /></Frame>

In **Ethernet Settings**, select **Static** and fill in the details.

<Frame><img src="/images/image-14.png" alt="Static option selected in the VPOS Media 5 Ethernet Settings" /></Frame>
